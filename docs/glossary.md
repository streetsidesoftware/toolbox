# Glossary

The words these packages use for their ideas, in code, comments and docs.

## Placeholder

A marker in a template, such as `{@ name @}`, that a replacement takes the place of.

## Replacement

What takes a placeholder's place. Use this word in names, comments and docs.

Don't call it a "value". Nearly everything in code is a value, so the word doesn't say what it's for.
